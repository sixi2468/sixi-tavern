手机与电脑连同一个 Wi-Fi 时最快
—
在电脑上打开

打不开怎么办

1. 确认手机连的是同一个 Wi-Fi，别连访客网络；
2. 手机别用 localhost，那是手机自己；
3. Windows 首次运行 Python 时若点了「取消」，入站会被防火墙拦——以管理员身份执行一次 netsh advfirewall firewall add rule name="四夕酒馆" dir=in action=allow protocol=TCP localport=8000；
4. 还是不行就回到电脑，用「公网演示」脚本生成一个临时 https 地址。
