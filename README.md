# 四夕酒馆 · 读书笔记（网页原型 v0.9）

一个可以**直接双击打开**的读书笔记站点原型：登录注册、我的书架、按书写笔记、分类、封面导入、ISBN 导入、分享与匿名、酒肆信息流、评论加权排序、当赏动画、屏蔽词、审核队列、广告位、馆主后台，全部可用。

> 这是**前端原型**：数据存在浏览器本地（localStorage），刷新不丢，换设备/清缓存会丢。
> 正式上线需要接后端，方法见 `docs/03-上线教程.md`。

---

## 一、最快预览（30 秒）

方式 A：直接双击 `index.html`（Chrome / Edge / Safari 均可）。

方式 B（更稳，推荐）：在本目录执行

```bash
python3 -m http.server 8000
```

然后浏览器打开 <http://127.0.0.1:8000>。

## 四、改东西从哪儿下手

| 想改的 | 改哪里 |
|---|---|
| 配色 / 字体 / 圆角 | `assets/css/main.css` 顶部 `:root` 变量 |
| 全站文案、菜单 | `assets/js/app.js` 的 `NAV` 数组 + 各页面 HTML |
| 种子内容（示例书与笔记） | `assets/js/store.js` 的 `BOOK_SEED` / `NOTE_SEED` |
| 屏蔽词 | 页面里改，或直接改 `assets/data/blockwords.txt` 后导入 |
| 封面题签字号 | `assets/js/app.js` 的 `coverHTML()` 里 `fs` 一行 |
| 匿名权重 | `assets/js/store.js` 的 `weight = likes * (anonymous ? 2/3 : 1)` |

## 五、已知边界（原型阶段）

- 数据只在本机浏览器，**没有真实账号体系**，多设备不同步。
- 审核是本地模拟：命中屏蔽词进「待复核」，其余约 6 秒自动通过。
- ISBN 查询先查内置表，未命中时尝试 OpenLibrary 公开接口（需联网，国内可能较慢）。
- 后台指标基于本机访问记录生成，非真实统计。
- 已有：关注/取关、只看关注、关注者可见、举报、编辑/删除笔记与评论、草稿、改密码、政策页，
  以及分享卡（生成 1080×1440 PNG）、阅读小结、打印样式、PWA 离线。
- 已有：单篇 / 全量导出 Markdown（数据可迁移）、读屏与键盘可用的焦点样式、系统「减少动效」适配。
- 未做：找回密码、邮箱验证、关注列表页、消息通知。

这些都会在接入后端时一并解决，路线见 `docs/03-上线教程.md` 第五节。
