上线教程

先 A（免费上线）后 B（接后端）。每一步都写：点什么 → 会看到什么 → 不对怎么办。

0先认清你手里是哪个包

这一步最容易错，先看一眼文件夹。

你下载的特征你要做什么
上线包有 先看这里.txt、启动预览.bat，没有 tools直接用，不需要打包
源码包有 tools 文件夹、一键打包.bat想改代码才用
常见错误：在上线包里双击「一键打包」，会报 can't open file ...tools\prepare_release.py。上线包已经是成品，跳过这一步。

1本地先看一眼5 分钟

确认网站是好的，再去折腾上传。

你做什么

  1. 把压缩包解压到 路径里没有中文和空格 的地方，例如 D:\sixi\；
  2. 进入文件夹，双击 启动预览.bat（Mac 双击 启动预览.command）。

你会看到

黑窗口会显示一行地址（形如 http://127.0.0.1:8000，端口可能不同），浏览器自动打开。
黑窗口不要关，关了网站就停；出错时窗口会停住并显示错误码。

不对怎么办

黑窗口一闪就没没装 Python。去 python.org 装，勾选 Add Python to PATH
浏览器没弹出来手动打开浏览器，输入 http://localhost:8000
提示端口被占用脚本会自动换端口，以窗口显示的地址为准
页面空白你是双击 index.html 打开的，改用 启动预览.bat

2注册馆主账号2 分钟

后台权限靠邮箱识别。

你做什么

  1. 登录页点「注册」；
  2. 邮箱填打包时用的那个（例如 sixi2468@163.com）；
  3. 密码 ≥6 位，用户名随意，生日可跳过，勾选同意；
  4. 点「开一间自己的酒架」。
进入「我的酒架」，右上角能看到「后台」。
没有「后台」= 邮箱不是打包时填的那个。换邮箱重新注册，或用源码包重新打包并填对。

3传到 GitHub10 分钟

不需要装 Git，全程网页点击。

你做什么

  1. 打开 github.com，注册/登录；
  2. 右上角 + → New repository；
  3. 名字填 sixi-tavern，选 Public，点 Create repository；
  4. 点 uploading an existing file；
  5. 打开解压出来的文件夹，全选里面的内容（不是选文件夹），拖进网页；
  6. 等进度条走完，点 Commit changes。
仓库首页出现 index.html、assets 等文件。
如果变成 四夕酒馆-上线包/index.html（多了一层），删掉重传，要传的是文件夹里面的内容。

4Cloudflare Pages 部署10 分钟

这一步做完，网站就上线了。

你做什么

  1. 打开 dash.cloudflare.com，注册/登录；
  2. 左侧 Workers & Pages → Create → Pages → Connect to Git；
  3. 授权 GitHub，选中 sixi-tavern → Begin setup；
  4. 三个框：Framework None；Build command 留空；Output directory /；
  5. 点 Save and Deploy。
约 30 秒后出现 https://xxxx.pages.dev，点开就是你的网站。A 计划完成。
打开 404：输出目录没填 /。页面没样式：assets 没传上去。

5上线自测5 分钟

  • 手机 4G 能打开 pages.dev
  • 能注册、能写笔记、刷新还在
  • 笔记页「分享」能生成图片
  • 乱输一个地址（如 /abc）能看到 404 页
  • 只有馆主邮箱能看到「后台」
任意一条不过，把截图和网址发我。

6绑自己的域名可选 · 30 分钟

  1. 买域名并实名（阿里云/腾讯云）；
  2. Pages 项目 → Custom domains → Set up a custom domain；
  3. 填 notes.你的域名.com，按提示加 CNAME；
  4. 等 1–10 分钟，证书自动签。
用 Pages + 境外 DNS 不需要备案。

7B 计划：接后端1–2 天 · 可稍后

什么时候做：朋友说「看不到你写的笔记」时。那不是 bug，是纯静态的边界。

  1. 注册 supabase.com，新建项目（新加坡/东京）；
  2. SQL Editor 里粘贴 supabase/schema.sql 整段，点 Run；
  3. 把 assets/js/store.js 换成 Supabase 版本（见 docs/03-上线教程.md 第五节）；
  4. 重新部署。
手机注册的账号电脑能登录；你写的公开笔记别人能看到。

!报错对照表

报错 / 现象真正原因你该做什么
can't open file ...tools\prepare_release.py在上线包里跑了打包脚本不用打包，双击 启动预览.bat 或上传 GitHub
'python3' 不是内部或外部命令Windows 叫 python把命令里的 python3 换成 python
'python' 不是内部或外部命令没装或没勾 PATH重装 Python 3，勾 Add Python to PATH
双击 bat 闪退Python 没装好同上
浏览器显示无法访问黑窗口被关了，或浏览器用了 localhost 而服务在 127.0.0.1重新双击 启动预览.bat，用窗口里那行地址（127.0.0.1 开头）
部署后 404输出目录不对改成 / 重新部署
页面没样式assets 没传回 GitHub 补传 assets
注册后没有后台不是馆主邮箱用打包时填的邮箱注册
别人看不到我的笔记纯静态，各存各的做第 7 步（接后端）
