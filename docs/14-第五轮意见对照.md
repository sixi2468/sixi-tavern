## 细节

**分类（按你最新一条意见调整）**
- 平时：只有「分类名 + 数量」，**所有数字右对齐在同一列**，没有任何按钮；
- 悬停：该行数字往左滑 46px，右侧浮出 `⋯` 和三条横杠 `≡`；移开鼠标数字滑回原位；
- 排序：按住 `≡` 拖动整行；触屏设备在 `⋯` 里用「上移 / 下移」；
- 改名：双击分类名，或 `⋯` → 重命名；
- 删除：`⋯` → 删除，提示「N 本书会回到未分类」；
- 「全部藏书 / 未分类」是固定视图，不可改名/删除/拖动。

**生日**
- 三个下拉任意留空都不影响注册/保存；
- 选定年月后，日会自动限制在当月天数；
- 已存的生日会回填（如 1996-04-12）。
