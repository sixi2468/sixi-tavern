# 成本测算 · 从 0 元试水到正常运营

> 币种：人民币（元）。价格为 2026 年公开报价的**区间估算**，用于你做预算判断；
> 实际以下单时官网为准（云厂商活动价波动很大）。所有"月"按 30 天计。

---

## 一、先明确三件事

1. **这个站是"内容型小站"**：文字为主、图片为辅，没有视频和大文件，带宽压力很小。
2. **成本的大头不是服务器，是"合规"和"人力"**：域名备案免费但要时间；内容审核要么花钱买 API，要么自己耗时间盯。
3. **可以先 0 元上线**：纯静态托管（Cloudflare Pages / Vercel）免费且不限带宽，先用它接真实用户，验证有没有人写，再花钱上后端。

## 三、月度成本：三档方案

### 方案 A · 试水档（0–10 元/月）

适合：刚上线、日活 < 100、只想验证有没有人愿意写。

| 项目 | 选型 | 月成本 |
|---|---|---|
| 托管 | Cloudflare Pages（免费，无限带宽） | ¥0 |
| 数据库 | Cloudflare D1（免费 5GB）或 Supabase Free（500MB） | ¥0 |
| 图片 | Cloudflare R2（免费 10GB 存储 + 出网免费） | ¥0 |
| 域名 | .com 摊销 | ¥6 |
| 审核 | 本地词库 + 人工 | ¥0 |
| 邮件（找回密码） | Resend 免费 100 封/天 | ¥0 |
| **合计** | | **≈ ¥6 / 月** |

限制：Supabase 免费项目 7 天无请求会休眠；Cloudflare 免费版有请求数上限（每天 10 万，够 1 万 PV）。

> 这一档已经能撑住"日活一千、每人每天 5 页"的规模。文字站真正的瓶颈是审核和运营，不是机器。

## 四、按流量的粗略换算（自检用）

假设：每人每天 5 页，每页 350KB（含封面图，已压缩）。

| 日活 DAU | 月 PV | 月流量 | 静态托管 | 自建服务器 |
|---|---|---|---|---|
| 100 | 1.5 万 | ~5 GB | ¥0 | 2C2G 够用 |
| 1,000 | 15 万 | ~52 GB | ¥0 | 2C2G 3M 勉强，建议 CDN |
| 5,000 | 75 万 | ~260 GB | ¥0（Pages 不限带宽） | 4C4G + CDN ¥600+ |
| 20,000 | 300 万 | ~1 TB | 需看条款 | ¥2,000+/月 |

**结论**：在你这个体量，**静态托管 + Serverless 数据库**是最省的组合，比自建服务器便宜一个数量级，也省运维。

## 五、收入侧（什么时候能回本）

| 方式 | 门槛 | 现实预期 |
|---|---|---|
| Google AdSense | 有原创内容、隐私政策、域名；审核 1–2 周 | 国内流量每千次展示约 ¥1–5；15 万 PV × 2 个广告位 ≈ **¥300–1,500/月**（新站前 3 个月通常只有 ¥50–200） |
| 国内广告联盟（百度/穿山甲） | 一般要求**已备案**、企业资质 | 单价略高，但审核更严 |
| 打赏抽成 | 接微信/支付宝需企业主体 | 按 1% 付费率、人均 ¥5 估，1,000 DAU ≈ ¥150–400/月流水，抽 10% 即 ¥15–40 |
| 会员（去广告/自定义封面） | 需支付与账号体系 | 前期不建议，先把内容做起来 |

**回本线**：方案 B 的 ¥200/月，大约需要 **日活 300–500 且广告正常跑起来** 才能覆盖。

## 六、省钱与避坑

1. **别一上来买服务器**。先用免费静态托管跑 2 个月，看留存再决定。
2. **图片一定要压缩**。封面 700px 宽、质量 82，单张 40–80KB；不压缩会让带宽翻 5 倍。
3. **免费额度会睡觉**。Supabase 免费项目 7 天无请求会暂停，正式运营前要升 Pro 或加定时 ping。
4. **备案要趁早**。想接国内广告或放大陆服务器，备案 7–20 个工作日，别等上线了才办。
5. **审核别全靠人工**。1,000 条/天的量，人工看不完；机审 + 抽检最省。
6. **备份不花钱但要配**。数据库每日备份 + 每周导出一次 JSON 到本地，是唯一防止"全没了"的手段。
7. **不要买"终身免费"的野鸡主机**，跑路和数据丢失是常态。

## 七、一句话总结

- **现在就能上线**：¥6/月（只有域名）。
- **有人用了要升级**：约 ¥200/月，可撑日活一千。
- **要备案、要国内广告**：约 ¥300/月起，加带宽后 ¥600–900。
- **回本**：日活 300–500 + 广告正常，约 3–6 个月。
