## 两条规则，按你的要求口头说明（页面不写）

**热度权重**（酒肆「最热」、同书聚合、馆友主页共用）：

```
热度 = 赞 × 1 + 当赏壶数 × 3 + 评论数 × 2
匿名内容整体 × 2/3
```

参考的是内容社区常见做法：打赏是"真金白银"的行为，权重高于点赞；评论比点赞更重，但低于打赏。

**酒钱规则**：

```
每日首次登录      +3 壶
当赏一篇          -1 壶（余额不足会被拦下并引导去个人中心）
作者被赏满 5 壶    折 1 壶进作者余额（余数保留，继续累计）
```
