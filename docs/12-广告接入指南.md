# 广告接入指南（纯静态站能不能接？怎么接？）

> 结论：**能。广告和"静态/动态"无关**——广告就是一段 JS 或一个 `<iframe>`，
> 只要页面能被浏览器打开，就能挂。真正决定你能不能接、能赚多少的是
> **内容是否合规、有没有备案、流量在哪**，不是托管方式。

---

## 一、三条路，按门槛从低到高

| 方式 | 门槛 | 单价 | 适合 |
|---|---|---|---|
| **CPS 联盟**（京东/淘宝/当当图书） | 最低，注册即可 | 按成交抽佣 | 有书单、书评导购 |
| **Google AdSense** | 中等：原创内容 + 隐私政策 + 域名 | 国内流量 RPM 偏低 | 有稳定海外/混合流量 |
| **国内广告联盟**（百度联盟等） | 较高：**ICP 备案** + 常需企业资质 | CPM 中等 | 已备案、日活上千 |
| **直售/赞助** | 靠谈 | 最高 | 有明确读者群（如读书社群） |

> 你现在的站：**没备案也能先接 AdSense 或 CPS**；要接百度联盟，得先备案。

## 二、Google AdSense（静态站最常见）

### 2.1 申请前必须有的东西

1. **原创内容**：至少 20–30 篇像样的笔记（不是采集/拼凑）；
2. **必备页面**：关于、隐私政策、用户协议、联系方式（本站已内置前三项）；
3. **域名**：能正常访问、HTTPS；
4. **年龄与账号**：18 岁以上，一个 Google 账号只能一个 AdSense 账号。

### 2.2 步骤

1. 打开 `adsense.google.com` → 用 Google 账号登录 → 添加网站（填域名）；
2. 验证所有权：按提示加一条 DNS TXT 记录，或上传验证文件；
3. 提交审核（通常 1–14 天，可能被拒多次，按提示补内容）；
4. 通过后创建"展示广告"单元，拿到一段 `<ins class="adsbygoogle" ...>` + `<script>`；
5. 把代码粘到本站后台 → 广告位 → 对应位置 → 保存；
6. 在站点根目录放 `ads.txt`（本站已提供模板，把 `pub-XXXX` 换成你的 ID 并取消注释）。

### 2.3 本站怎么放

- 后台 → 广告位 → `tavern-feed-1`（酒肆第 6 张卡片下）或 `note-bottom-1`（笔记正文底部）；
- 粘贴联盟给的整段代码 → 保存 → 前台刷新即可生效；
- 代码里的 `<script>` 会被重新创建并执行，不需要你手动改 HTML；
- 没填代码时：馆主能看到占位框，普通访客看不到（不会出现空框）。

### 2.4 常见被拒原因

| 原因 | 解决 |
|---|---|
| 内容太少 / 空洞 | 先写 20 篇再申请 |
| 缺隐私政策/关于/联系 | 本站已内置，补上联系邮箱即可 |
| 有版权内容（大段摘抄） | 改成引用 + 自己的解读 |
| 导航不清、移动端错位 | 用本站现成布局即可 |
| 域名是免费二级域 | 换独立域名 |
| 多次重复申请 | 间隔 2 周，先补内容 |

## 三、国内广告联盟

### 3.1 硬门槛

- **ICP 备案**（必须，且域名与备案主体一致）；
- 多数要求**企业主体**（个人站可选百度联盟的"个人站长"入口，但审核更严）；
- 内容合规、无侵权、无诱导点击；
- 部分联盟要求**日 UV ≥ 500–1000**。

### 3.2 可选平台

| 平台 | 类型 | 备注 |
|---|---|---|
| 百度联盟 | 展示/搜索 | 需备案，个人可尝试 |
| 京东联盟 / 淘宝客 | CPS | 图书类目佣金低但转化好 |
| 当当/孔夫子联盟 | CPS | 二手书、绝版书有优势 |
| 360/搜狗联盟 | 展示 | 量小，门槛类似 |

> 读书类站点，**CPS 往往比展示广告更实际**：一篇书评带购买链接，佣金 2%–10%。

## 四、收入大概多少（别抱太高期待）

| 流量 | AdSense（国内流量） | 国内联盟 | CPS |
|---|---|---|---|
| 1 万 PV/月 | ¥10–60 | 难开通 | ¥0–50 |
| 10 万 PV/月 | ¥100–600 | ¥50–300 | ¥100–500 |
| 50 万 PV/月 | ¥500–3000 | ¥300–1500 | ¥500–3000 |

> 关键变量是**流量来源**：欧美流量 RPM 可以是国内的 5–10 倍。
> 新站前三个月基本只有几块到几十块，这是正常的。

## 五、合规红线（踩了会被封号）

1. **必须标"广告"**：广告位旁边要有可识别的标识；
2. **不得诱导点击**（"点一下支持我"这类）；
3. **不得遮挡内容**、不得自动弹窗、不得与内容混淆；
4. **Cookie 同意**：欧盟流量需要同意横幅；
5. **隐私政策**要写明第三方广告与 Cookie（本站已写）；
6. **未成年人**：不得对未成年人做定向广告；
7. **不要自己点自己的广告**——这是最常见的封号原因。

## 六、性能与体验

- 广告脚本会拖慢首屏：放在**内容之后**、加 `loading="lazy"`（iframe 类）；
- 每个页面**不超过 2 个**广告位；
- 移动端不要放 300×600 的大块，容易顶掉正文；
- 用固定高度容器，避免布局跳动（CLS）。

## 七、本站的实现（给维护者）

| 项 | 说明 |
|---|---|
| 广告位标记 | `<div data-ad-slot="tavern-feed-1">`（另有 `note-bottom-1`、`note-side-1`） |
| 配置存储 | `localStorage.sixi_v3.adSlots`（后台可改） |
| 渲染 | `UI.renderAds()`：读配置 → 有代码则注入并执行 script → 无代码则仅馆主可见占位 |
| 分享卡 | 不设广告位（保持画面干净） |
| ads.txt | 站点根目录，模板已给 |
| 位置 | 酒肆第 6 张卡片下、笔记正文底部、笔记右侧栏底部 |

> 安全提醒：后台粘贴的代码会以**本站权限**执行，只粘贴你信任的联盟代码。

## 八、给你的建议顺序

1. 先写 20 篇原创笔记，把隐私/关于/联系补齐；
2. 申请 AdSense（不备案也能试）；
3. 同时挂京东/当当 CPS（几乎无门槛，读书站天然适配）；
4. 日活过千、决定长期做，再备案接国内联盟；
5. 广告位永远不超过 2 个，别为了几块钱毁掉阅读体验。
