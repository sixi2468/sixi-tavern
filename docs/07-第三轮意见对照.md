## 关于 ISBN，说清楚一点

现在的查询顺序：

1. **内置表（28 本）**——离线可用，秒出；
2. **OpenLibrary**（`openlibrary.org/isbn/<isbn>.json`）——国际书目，国内网络**可能连不上**；
3. **Google Books**（`books.googleapis.com`）——同上，国内**经常不可用**；
4. 三者都失败 → 直接带入 ISBN，让你手填书名与出版社（不再只弹一句"未收录"）。

所以：**能用，但国内网络命中率有限**。要稳定查中文书，正式上线时建议走自己的后端代理，接以下任一（都需要申请）：

- 豆瓣读书（官方 API 已关闭，多数项目走自建代理，注意合规）；
- 国家图书馆书目接口（需申请）；
- 商业 ISBN 库（如 ISBNdb、中文图书在版编目数据服务）。

后端代理还能顺便解决跨域和封面盗链。`03-上线教程.md` 第五节的 Supabase 方案可以直接加一个 Edge Function 做这事。
