# 上线执行方案 · 从今天到有第一个用户

> 这份是"照做就行"的施工方案，不是科普。
> 每个阶段都有：做什么、怎么做、多久、花多少钱、做完怎么验。
> 总耗时（不含备案）：**今天 2 小时能拿到网址，一周内能有真实账号体系**。

---

## 0. 先做一个选择

| 路线 | 适合 | 代价 |
|---|---|---|
| **A. 纯静态先上线**（推荐） | 先给人看、收集反馈 | 数据存在各自浏览器，**彼此看不到对方的笔记** |
| **B. 直接带后端** | 一开始就要"真的能互相看见" | 多花 1–2 天接 Supabase |

**建议：先 A 后 B。** 先用 1 小时拿到网址，发给 10 个人；确认有人愿意写，再接后端。
因为纯静态阶段"别人写的你看不到"，这一点必须提前知道，别上线后才发现。

## 不会用命令行？先看这一节

下面的命令都要在**解压后的 `site` 文件夹**里执行。不会开终端的话，三种办法：

### 办法一：双击脚本（最简单）

源码包根目录自带：

| 系统 | 双击 | 效果 |
|---|---|---|
| Windows | `一键打包.bat` | 提示输入馆主邮箱 → 自动生成 `release/` |
| macOS | `一键打包.command` | 同上（首次提示无法打开时：右键 → 打开） |
| Linux | 终端 `./一键打包.sh 你的邮箱` | 同上 |

生成完会告诉你下一步做什么，不用记命令。

### 办法二：在文件夹里直接开终端（Windows）

1. 打开资源管理器，进入解压后的 `site` 文件夹；
2. 点一下顶部的**地址栏**，把路径删掉，输入 `cmd`，回车；
3. 弹出的黑窗口就已经在这个目录里了（提示符前面是 `...\site>`）；
4. 粘贴命令执行。

> 也可以在文件夹空白处按住 `Shift` + 右键 → **在此处打开 PowerShell 窗口**。

### 办法三：macOS 右键开终端

1. 在 Finder 里找到 `site` 文件夹；
2. 右键 → **服务** → **新建位于文件夹位置的终端窗口**；
3. 或者先打开"终端"，输入 `cd `（注意后面有个空格），把文件夹**拖进终端窗口**，回车。

### 怎么确认自己在对的目录

```bash
ls        # macOS / Linux
dir       # Windows
```

能看到 `index.html`、`assets`、`tools`、`docs` 就对了。看不到就是进错文件夹了。

### 命令里的 `python3` 和 `python`

- macOS / Linux：一般用 `python3`；
- Windows：多半是 `python` 或 `py -3`。报 **“'python3' 不是内部或外部命令”** 就换成 `python` 再试。

## 阶段 0 · 打包与本地自测（30 分钟，¥0）

### 0.1 生成上线包

在 `site/` 目录执行：

```bash
python3 tools/prepare_release.py --empty --owner-email "你的邮箱@example.com"
```

它会：

- 复制出一份 `release/`；
- **删掉演示后门**（"以馆主身份进入"按钮、示例账号提示）；
- 打开 `emptySeed`（不再预置假用户和示例书）；
- 把你的邮箱设为馆主：**用这个邮箱注册的账号自动有后台权限**；
- 如果没传 `--owner-email`，则**第一个注册的账号自动成为馆主**（适合先上线再说）。

> 不想清空示例内容？去掉 `--empty`，站会看起来"已经有人"。

### 0.2 本地跑一遍

```bash
cd release
python3 -m http.server 8000
```

打开 `http://localhost:8000`，逐项确认：

- [ ] 注册（人机验证能过）→ 自动进酒架
- [ ] 用馆主邮箱注册 → 能看到「后台」
- [ ] 添加一本书 → 写一篇笔记 → 出现在书籍页
- [ ] 当赏动画、分享卡（保存图片）正常
- [ ] 手机宽度下没有横向滚动
- [ ] 控制台无红色报错

## 阶段 1 · 免费上线（1 小时，¥0）

### 1.1 传到 GitHub

1. 注册/登录 github.com；
2. 右上角 `+` → New repository → 名字 `sixi-tavern` → Public → Create；
3. Add file → Upload files → **把 `release/` 里的所有内容拖进去**（`index.html` 要在根目录）；
4. Commit。

> 不要上传外层 `release` 文件夹本身，否则线上路径会多一层。

### 1.2 Cloudflare Pages

1. 注册 dash.cloudflare.com；
2. Workers & Pages → Create → Pages → Connect to Git；
3. 选仓库 → Framework preset：**None**；
4. Build command：**留空**；Build output directory：**`/`**；
5. Save and Deploy → 30 秒后得到 `https://xxx.pages.dev`。

### 1.3 上线自测

- [ ] 无痕窗口打开 `pages.dev` 地址
- [ ] 注册 → 写笔记 → 刷新还在
- [ ] 手机 4G 打开（不连 Wi-Fi）
- [ ] 随便输一个不存在的路径 → 出现 404 页（`_redirects` 生效）
- [ ] 分享卡能保存图片
- [ ] 后台只有馆主邮箱能进

✅ 到这里，**你已经有网址了**。可以发给朋友。

## 阶段 2 · 绑自己的域名（30 分钟 + DNS 等待，约 ¥70/年）

1. 买域名（阿里云/腾讯云/Namecheap 均可），完成实名；
2. Pages → Custom domains → Set up a custom domain → 填 `notes.你的域名.com`；
3. 按提示加 CNAME（Cloudflare 托管 DNS 的话一键完成）；
4. 等 1–10 分钟，证书自动签发；
5. 开 301：`http → https`，`www` 与裸域只留一个。

验收：

- [ ] `https://` 打开无警告
- [ ] `http://` 自动跳 `https://`
- [ ] 手机能打开

> 用 Pages + 境外 DNS **不需要备案**。

## 阶段 3 · 接后端（1–2 天，¥0–186/月）

这一阶段解决三件事：**账号真实存在、数据跨设备、别人能看到你的公开笔记**。

### 3.1 建 Supabase

1. 注册 supabase.com → New project（选新加坡/东京）；
2. SQL Editor → 把 `supabase/schema.sql` 整段贴进去 → Run；
3. Authentication → Providers → Email：内测期可先关掉 "Confirm email"；
4. Storage → 确认 `covers` 桶为 public。

### 3.2 改前端

按 `docs/03-上线教程.md` 第五节，把 `assets/js/store.js` 的读写换成 Supabase API。
页面只调用 `Store.xxx()`，**函数签名不变**，所以只改这一个文件。

### 3.3 迁移已有内容（可选）

设置 → 导出数据（JSON）→ 用脚本导入 Supabase 的 `books / notes` 表。
字段映射见 `docs/04-维护手册.md` 第 9.2 节。

### 3.4 验收

- [ ] 手机注册的账号，电脑能登录
- [ ] A 写的公开笔记，B 能在酒肆看到
- [ ] 「仅关注者可见」：未关注看不到，关注后能看到
- [ ] 点赞/评论数正确
- [ ] 封面图能上传、能显示

## 阶段 4 · 上线运营（持续）

### 第一周每天 10 分钟

- 清空审核队列
- 看「驿站来信」
- 看后台 DAU、停留时长

### 第一周看三个数

1. 有多少人注册（转化）；
2. 有多少人写了第一篇（激活）；
3. 有多少人第二天回来（留存）。

> 三个数都很低，说明问题在产品，不在服务器。

### 备份

- 每周五：设置 → 导出 JSON / Markdown，存网盘；
- 接后端后：Supabase 每日自动备份 + 每月手动导一次。

## 阶段 5（可选）· 国内备案与迁移（2–4 周，¥200–350/月）

什么时候做：要接百度联盟、要国内低延迟、要长期做。

1. 域名备案（7–20 工作日，见 `11-域名购买与备案.md`）；
2. 买轻量 2C2G，装 Nginx，传文件；
3. `certbot` 上 HTTPS；
4. 把 OSS 作为图片存储，CDN 加速；
5. DNS 切到国内服务器（提前把 TTL 调到 60）。

## 回滚与应急

| 情况 | 处理 |
|---|---|
| 新版本上线后白屏 | Pages → Deployments → 上一版 → Rollback |
| 域名打不开 | 查 DNS 是否生效、证书是否过期 |
| 数据异常 | 用最近备份恢复；先停止写入 |
| 被刷 | Cloudflare 开 Under Attack；关掉发帖入口 |
