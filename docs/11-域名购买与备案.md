# 域名购买、解析与备案 · 全流程

> 从"选一个名字"到"域名能打开、能备案、能续费"，每一步都写清楚。

---

## 一、域名是什么

域名是 IP 的别名。你买的是**使用权**（按年租），不是所有权。
结构：`子域名 . 主域名 . 后缀` —— 例如 `notes.sixi.art`：
`notes` 是子域名，`sixi` 是主域名，`.art` 是后缀（TLD）。

**买之前先想清楚三件事**：

1. **名字**：好记、好拼、不要太长（≤ 12 个字母最佳）；
2. **后缀**：`.com` 最通用，`.cn` 国内合规友好，`.art/.me/.io` 更有调性但贵；
3. **用途**：个人博客 / 商业站 / 品牌保护，决定你买几个后缀。

---

## 二、后缀怎么选

| 后缀 | 首年价 | 续费价 | 适合 | 注意 |
|---|---|---|---|---|
| `.com` | ¥30–90 | ¥70–100 | 通用、最稳 | 好名字基本被注册完 |
| `.cn` | ¥20–40 | ¥35–60 | 国内站、备案友好 | 必须实名 |
| `.net` | ¥60–90 | ¥90–120 | 技术类 | 认知度低于 .com |
| `.org` | ¥70–110 | ¥100–140 | 非营利、社区 | 商业也能用 |
| `.io` | ¥200–400 | ¥300–500 | 开发者产品 | 贵，续费更贵 |
| `.me` | ¥60–150 | ¥120–200 | 个人主页 | 续费涨幅大 |
| `.art` | ¥80–150 | ¥120–200 | 文创、艺术 | 小众但有辨识度 |
| `.xyz` | ¥10–30 | ¥60–90 | 廉价、实验 | 部分邮箱会判为垃圾 |
| `.top/.cc/.vip` | ¥5–30 | ¥30–80 | 便宜 | 信任度低，慎用于正式站 |

> 建议：正式站买 `.com`，同时把 `.cn` 和常见拼写错误域名一起注册（防抢注），
> 一年也就多几十块。

**取名避坑**：

- 不要用连字符（`my-site` 容易被念错、被判垃圾站）；
- 不要用数字和字母混排（`sixi99` 容易记错）；
- 避开已有商标的词（上线后被投诉会丢域名）；
- 中文域名（`.中国`）兼容性差，不建议做主站。

## 三、在哪买：注册商对比

### 国内注册商

| 注册商 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **阿里云（万网）** | 备案一站式、DNS 稳定、发票方便 | 续费偏贵、界面复杂 | 要备案的站 |
| **腾讯云** | 与微信/云开发打通、活动多 | 同上 | 要备案 + 小程序 |
| **华为云** | 企业采购友好 | 个人体验一般 | 企业 |
| **新网 / 西部数码** | 老牌、便宜 | 界面老旧、推销多 | 预算敏感 |

### 国外注册商

| 注册商 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **Cloudflare Registrar** | **按成本价卖**、免费隐私保护、DNS 一体 | 只能转入，不能新注册 | 已有机域名 |
| **Namecheap** | 首年便宜、送隐私保护 | 续费涨价、upsell 多 | 个人 |
| **Porkbun** | 价格透明、界面清爽 | 国内访问后台偶尔慢 | 个人/小团队 |
| **GoDaddy** | 名气大 | 续费贵、推销凶猛 | 不推荐新手 |
| **Dynadot** | 稳定、支持支付宝 | 价格中等 | 国内用户 |

> 结论：
> - **要备案** → 在阿里云/腾讯云买，省得跨平台折腾；
> - **不备案** → Cloudflare（转入）或 Porkbun/Namecheap（新注册）。

## 四、购买步骤（四个平台各一遍）

### 4.1 阿里云（推荐给要备案的人）

1. 打开阿里云 → 搜索"域名注册"；
2. 输入名字，看后缀与价格，加入清单；
3. 选**信息模板**（个人：身份证；企业：营业执照），没有就新建；
4. 支付（1 年起，建议直接买 3 年，省得忘续费）；
5. 实名认证：身份证正反面 + 人脸，1–3 个工作日；
6. 实名通过后才能解析（未实名会被暂停解析）。

### 4.2 腾讯云

流程几乎一样：域名注册 → 信息模板 → 支付 → 实名。
优势是备案时和云服务器在同一个控制台，材料不用重复上传。

### 4.3 Cloudflare（已有机域名转入）

1. 在 Cloudflare 添加站点，拿到两个 NS；
2. 回原注册商把 NS 改成 Cloudflare 的；
3. 等生效（几分钟到 24 小时）；
4. Billing → Transfer Domains，按成本价续一年；
5. 自动获得免费隐私保护与 DNSSEC。

> 注意：Cloudflare Registrar 不支持新注册，只能转入；`.cn` 等部分后缀不支持。

### 4.4 Namecheap / Porkbun（不备案的新注册）

1. 搜索名字 → 加入购物车；
2. 关掉所有 upsell（SSL、邮箱、主机都不需要）；
3. 开 **WhoisGuard / 隐私保护**（一般免费）；
4. 用支付宝/信用卡支付；
5. 邮箱验证后即可解析。

## 五、DNS 解析：五条记录搞定

| 类型 | 主机记录 | 值 | 用途 |
|---|---|---|---|
| A | `@` | 服务器 IPv4 | 主域名指向服务器 |
| A | `www` | 服务器 IPv4 | www 子域 |
| CNAME | `notes` | `xxx.pages.dev` | 指向托管平台 |
| CNAME | `www` | `xxx.pages.dev` | Pages 的 www |
| TXT | `@` | `v=spf1 ...` | 邮件防伪造 |
| MX | `@` | 邮件服务商 | 收邮件 |
| AAAA | `@` | IPv6 | 可选 |

- **TTL**：调试时设 60 秒，稳定后设 600–3600 秒。
- **CNAME 不能与 A 记录同名**，否则冲突。
- 换服务器时先改 TTL 为 60，等一天再切，能秒级生效。

## 六、ICP 备案（大陆服务器必看）

### 6.1 谁需要

- 服务器在**中国大陆** → 必须备案；
- 服务器在香港/海外 → 不需要（但访问速度与广告联盟会受影响）；
- 只解析到 Cloudflare Pages → 不需要。

### 6.2 个人 vs 企业

| | 个人 | 企业 |
|---|---|---|
| 主体材料 | 身份证 | 营业执照 + 法人身份证 |
| 网站名称 | 不能含"公司/商城/新闻"等 | 可与主体相关 |
| 内容限制 | 不能做经营性内容 | 可申请经营性备案 |
| 耗时 | 7–20 工作日 | 10–20 工作日 |

### 6.3 材料清单

- 主体证件（身份证正反面 / 营业执照）；
- 负责人手机号、邮箱；
- 域名证书（注册商后台下载）；
- 服务器实例（需购买 ≥3 个月的套餐）；
- 部分省份要**幕布拍照**或视频核验；
- 网站备案信息真实性核验单（在线签）。

### 6.4 流程

1. 在云厂商备案系统提交（阿里云/腾讯云控制台 → 备案）；
2. 初审（1–3 天，客服电话核对）；
3. 管局审核（7–20 个工作日）；
4. 通过后收到备案号（如 `京ICP备2026xxxxxx号-1`）；
5. **30 日内**做公安联网备案（beian.mps.gov.cn）；
6. 把备案号放到网站页脚，并链接到 `beian.miit.gov.cn`。

### 6.5 常见驳回原因

| 原因 | 解决 |
|---|---|
| 网站名称含"酒馆/商城/新闻"等敏感词 | 改成"读书笔记分享"或个人博客类目 |
| 域名所有者与备案主体不一致 | 先过户域名 |
| 手机号/邮箱重复使用 | 换未用过的 |
| 服务器购买时长不足 3 个月 | 续费 |
| 网站打不开或内容不符 | 先放一个简单首页 |
| 身份证照片模糊/反光 | 重拍 |

### 6.6 变更与注销

- 换服务器、换主体、换域名 → 做**备案变更**；
- 网站不做了 → 主动注销，否则可能被列入异常名单；
- 备案信息过期未更新 → 可能被注销接入。

### 6.7 经营性备案（ICP 许可证）

如果你要**收费**（会员、打赏抽成、广告代理），严格来说需要 `ICP 经营许可证`，
门槛：注册资本 100 万、社保人数、场地等。个人站一般只做"非经营性备案"，
靠广告联盟分成通常按"非经营性"处理，但要以当地管局口径为准。

## 七、HTTPS 证书

| 方式 | 成本 | 说明 |
|---|---|---|
| Cloudflare 自动 | ¥0 | 最省事，Orange Cloud 开启即用 |
| Let's Encrypt + certbot | ¥0 | 90 天自动续期 |
| 云厂商免费证书 | ¥0 | 阿里云/腾讯云各有一年免费额度 |
| 付费 DV/OV/EV | ¥100–3000/年 | 一般小站不需要 |

Nginx 配好之后一条命令：

```bash
sudo certbot --nginx -d example.com -d www.example.com
```

**务必开启 301 跳转**：`http → https`、`www → 非 www`（或反过来），只保留一个主域。

## 八、域名安全

1. **开启隐私保护**：Whois 里不显示你的手机号与邮箱；
2. **开启域名锁**（Registrar Lock）：防止被恶意转移；
3. **开启双重验证**：注册商账号必须开 2FA；
4. **续费提醒**：设日历提醒，或直接买 3–5 年；
5. **防抢注**：品牌名把 `.com/.cn/.net` 一起注册；
6. **不要用免费域名**（`.tk/.ml` 等）：会被邮箱与广告平台判为垃圾。

---

## 九、迁移与转移

- **换 DNS**：改 NS 即可，解析记录要提前在新 DNS 建好；
- **转移注册商**：需要转移码（Auth Code）+ 解锁 + 等 5–7 天；
- **转移前确认**：域名注册满 60 天、未过期、未欠费；
- **转移不影响备案**，但备案主体信息要一致。

## 十、常见问题

**Q：域名一年多少钱？**
`.com` 首年 ¥30–90，续费 ¥70–100；`.cn` 更便宜；`.io` 要 ¥300+。

**Q：可以先买域名不备案吗？**
可以，但不能解析到大陆服务器。放境外托管没问题。

**Q：备案要多久？**
7–20 个工作日，个别省份更久。加急没有官方渠道，别信"当天备案"。

**Q：备案要花钱吗？**
官方免费；云厂商可能收"备案服务费"（一般 0 元）。

**Q：域名和服务器必须同一家吗？**
不需要。但同家备案更省事（材料复用）。

**Q：一个人能备案几个域名？**
各省不同，一般个人 5 个以内；企业更多。

**Q：备案后能改网站内容吗？**
能，但不能超出备案时填的网站性质（个人博客不能变成商城）。

**Q：海外域名能备案吗？**
可以，只要域名注册商在工信部白名单内；不在白名单的需先转入国内注册商。

**Q：不备案会怎样？**
解析到大陆服务器会被拦截（显示"未备案"页），广告联盟也无法过审。

**Q：域名过期多久会被删？**
一般有 30 天赎回期（高价赎回），之后进入删除期，可能被抢注。

## 十一、给你的具体建议

1. **现在就买**：`sixi.art` 或 `sixi-tavern.com`，先买 3 年；
2. **同时注册** `.cn` 与常见错拼（`sixitavern.com`），防抢注；
3. **第一版用 Cloudflare Pages**，不备案，先上线收集反馈；
4. **决定接国内广告时再备案**，用阿里云/腾讯云一站式搞定；
5. **备案期间**网站可以先放境外，等备案下来再切 DNS（TTL 提前调 60 秒）。
