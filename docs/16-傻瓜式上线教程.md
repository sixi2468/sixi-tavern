# 傻瓜式上线教程（先 A 后 B）

> 写给完全不想碰代码的人。
> 每一步都写了：**你点什么 → 会看到什么 → 不对怎么办**。
> A = 免费上线（30–60 分钟）；B = 接后端让数据真正互通（1–2 天，可以以后再做）。

---

## 第 0 步：先搞清楚你手里是哪个包（很重要）

你很可能就是卡在这里。

| 你下载的 | 里面有什么 | 你要做什么 |
|---|---|---|
| **四夕酒馆-上线包.zip** | 已经打包好的网站（`index.html`、`assets`、`docs`、`先看这里.txt`） | **直接用**：本地预览，或上传 GitHub。**不需要再打包** |
| **四夕酒馆-网站源码.zip** | 源码 + `tools/` + `一键打包.bat` | 想改代码才用它；改完点 `一键打包.bat` 生成上线包 |

> 你刚才的报错：
> `can't open file '...\四夕酒馆-上线包\tools\prepare_release.py'`
> 就是因为在**上线包**里运行了**源码包**才有的打包脚本。
> 上线包已经是成品，**这一步跳过**。

### 怎么一眼认出来

打开文件夹看：

- 有 `tools` 文件夹、`一键打包.bat` → **源码包**
- 有 `先看这里.txt`、`启动预览.bat`、没有 `tools` → **上线包**

## 第 1 步：本地先看一遍（5 分钟）

### 你做什么

1. 解压 `四夕酒馆-上线包.zip` 到一个**路径里没有中文和空格**的地方，例如 `D:\sixi\`；
2. 进入文件夹，双击 **`启动预览.bat`**（Mac 双击 `启动预览.command`）。

### 你会看到

- 弹出一个黑窗口，里面写着（**端口可能不是 8000**）：
  ```
  四夕酒馆已启动
    本机：http://127.0.0.1:xxxxx
    手机（与电脑连同一个 Wi-Fi）：
      http://192.168.x.x:xxxxx
  ```
- 2 秒后浏览器自动打开这个地址。
- 浏览器自动打开登录页。
- **黑窗口不要关**，关了网站就停了。

### 不对怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 黑窗口一闪就没 | 没装 Python | 去 python.org 装 Python 3，安装时勾选 **Add Python to PATH**，再双击 |
| 浏览器没自动开 | 正常，有的系统不弹 | 手动输入窗口里那行 `http://127.0.0.1:端口` |
| 提示 `localhost 拒绝了我们的连接` | 用了 localhost，服务只监听 IPv4 或端口不同 | 改用窗口里的 `127.0.0.1:端口` |
| 窗口还是闪退 | Python 启动失败 | 新脚本会停住并显示错误码；截图发我 |
| 提示端口被占用 | 8000 被别的程序用了 | 不用管，窗口里会显示 8001，用它那个地址 |
| 页面空白/没样式 | 双击的是 `index.html` | 用 `启动预览.bat` 打开，不要直接双击 html |

## 第 2 步：注册你自己的馆主账号（2 分钟）

### 你做什么

1. 在登录页点 **注册**；
2. 邮箱填 **`sixi2468@163.com`**（你打包时填的那个馆主邮箱）；
3. 密码 ≥6 位，用户名随便取，生日可跳过，勾选同意；
4. 点 **开一间自己的酒架**。

### 你会看到

直接进入「我的酒架」，右上角能看到「后台」。

### 不对怎么办

| 现象 | 怎么办 |
|---|---|
| 提示「人机验证不对」 | 把输入框上方/占位符里的算式算一下，填结果 |
| 提示「这个名字里有不适合的词」 | 换个用户名 |
| 注册后没有「后台」 | 说明注册邮箱不是打包时填的馆主邮箱；换那个邮箱重新注册（或用源码包重新打包并填对邮箱） |

## 第 3 步：把网站传到 GitHub（10 分钟）

> 不需要装 Git，全程网页点。

### 你做什么

1. 打开 <https://github.com>，注册/登录；
2. 右上角 **+** → **New repository**；
3. 名字填 `sixi-tavern` → 选 **Public** → 点 **Create repository**；
4. 在新页面点 **uploading an existing file**；
5. 打开你解压出来的文件夹，**全选里面的内容**（`index.html`、`assets`、`docs` 等一起），拖进网页的上传框；
6. 等进度条走完，点底部 **Commit changes**。

### 你会看到

仓库首页出现 `index.html`、`assets` 等文件。

### 不对怎么办

| 现象 | 怎么办 |
|---|---|
| 上传后多了一层文件夹（如 `四夕酒馆-上线包/index.html`） | 删掉重传：要传的是**文件夹里面的内容**，不是文件夹本身 |
| 提示文件太大 | 说明传了 zip；不要传压缩包，传解压后的文件 |
| 上传卡住 | 文件多时慢，等；或分两次传（先传 html，再传 assets） |

---

## 第 4 步：Cloudflare Pages 部署（10 分钟）

### 你做什么

1. 打开 <https://dash.cloudflare.com>，注册/登录（邮箱验证一下）；
2. 左侧 **Workers & Pages** → **Create** → 选 **Pages** → **Connect to Git**；
3. 授权 GitHub，选中 `sixi-tavern` → **Begin setup**；
4. 三个框这样填：
   - Framework preset：**None**
   - Build command：**留空**
   - Build output directory：**`/`**
5. 点 **Save and Deploy**。

### 你会看到

- 等 30 秒左右，出现 `https://xxxx.pages.dev`；
- 点开它，就是你刚才本地看到的网站。

**到这里，A 计划完成——网站已经上线了。**

### 不对怎么办

| 现象 | 怎么办 |
|---|---|
| 部署成功但打开 404 | 输出目录没填 `/`；回项目 Settings → Builds 改成 `/` 重新部署 |
| 页面没样式 | 上传时漏了 `assets` 文件夹，回 GitHub 补传 |
| 一直 Building | 等 2 分钟；超过就点 Deployments 看日志 |
| 国内打开很慢 | 正常，Pages 没有大陆节点；以后可以走备案 + 国内服务器 |

## 第 6 步（可选）：绑自己的域名（30 分钟）

1. 买域名（阿里云/腾讯云），完成实名；
2. Cloudflare Pages 项目 → **Custom domains** → **Set up a custom domain**；
3. 填 `notes.你的域名.com`，按提示加 CNAME；
4. 等 1–10 分钟，证书自动签。

> 用 Pages **不需要备案**。

---

## 第 7 步（B 计划）：接后端，让数据真正互通

**什么时候做**：你发现"朋友注册后看不到我写的笔记"——这不是 bug，是纯静态的边界。

### 你要做的事（概要）

1. 注册 <https://supabase.com>，新建项目（选新加坡/东京）；
2. 打开 SQL Editor，把我们给的 `supabase/schema.sql` 整段粘进去，点 Run；
3. 找开发者帮你把 `assets/js/store.js` 换成 Supabase 版本（`docs/03-上线教程.md` 第五节有完整代码）；
4. 重新部署。

### 你会看到

- 手机注册的账号，电脑也能登录；
- 你写的公开笔记，别人能在酒肆看到。

这一步建议找人代做（1–2 小时的事），或者按 `03-上线教程.md` 一步步来。

## 出错对照表（按你可能会遇到的顺序）

| 报错/现象 | 真正原因 | 你该做什么 |
|---|---|---|
| `can't open file ...\tools\prepare_release.py` | 在上线包里跑了打包脚本 | 上线包不用打包，直接 `启动预览.bat` 或上传 GitHub |
| `'python3' 不是内部或外部命令` | Windows 叫 `python` | 命令里把 `python3` 换成 `python` |
| `'python' 不是内部或外部命令` | 没装 Python / 没勾 PATH | 装 Python 3，勾 Add Python to PATH |
| 双击 bat 闪退 | Python 没装好 | 同上；或用 `启动预览.bat` |
| `Permission denied`（Mac） | 脚本没有执行权限 | 终端里 `chmod +x 启动预览.command` |
| 浏览器打开是"无法访问" | 黑窗口关了/服务没起 | 重新双击 `启动预览.bat`，窗口别关 |
| 部署后 404 | 输出目录不对 | 改成 `/` 重新部署 |
| 页面没样式 | `assets` 没传上去 | 回 GitHub 补传 `assets` 文件夹 |
| 注册后没有后台 | 邮箱不是馆主邮箱 | 用打包时填的邮箱注册，或重新打包 |
| 别人看不到我的笔记 | 纯静态，各存各的 | 这是 B 计划要解决的（接 Supabase） |

## 一句话总结

1. 你手里是**上线包** → 不要打包；
2. 双击 `启动预览.bat` 先看；
3. 注册馆主账号；
4. 文件传 GitHub；
5. Cloudflare Pages 连仓库，输出目录填 `/`；
6. 拿到 `pages.dev` 就成功了。

B 计划（接后端）等有人真的来用了再做，不急。
